Sign a message using a wallet address.

--pact-id is the pact that scopes the signing key and wallet; obtain it from
'caw pact list' or a pact submit response.

Usage:
  caw tx sign-message [flags]

Flags:
      --chain-id string            Chain ID, e.g. SETH, BASE_ETH (required). Use the List supported chains operation to retrieve all supported chain IDs
      --context string             Request context as JSON, saved with the response ID for tracking
      --description string         Human-readable description of what is being signed
      --destination-type string    Signing scheme, e.g. eip712 for EIP-712 typed data
      --eip712-typed-data string   EIP-712 typed data as a JSON object (required for eip712 destination type)
  -h, --help                       help for sign-message
      --pact-id string             Pact UUID [required]
      --request-id string          Client-supplied idempotency key
      --src-address string         Address to sign with. If omitted, the server auto-selects the wallet address on this chain (explicit src-address takes precedence)

Global Flags:
      --api-key string   API key for authentication
      --api-url string   API base URL to target a specific environment (env: AGENT_WALLET_API_URL)
      --timeout float    HTTP timeout in seconds (default 30)
  -v, --verbose          Enable debug logging
