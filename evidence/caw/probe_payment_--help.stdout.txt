Manage Cobo payment features including MPP (Merchant Payment Protocol) sessions and payment gateway configuration.

Use the session subcommand to inspect and manage active or historical payment sessions, and the gateway subcommand to configure payment gateway settings for the active wallet.

Usage:
  caw payment [command]

Available Commands:
  gateway     Start a payment-aware HTTP proxy gateway supporting x402 and MPP
  session     Manage MPP payment sessions

Flags:
  -h, --help   help for payment

Global Flags:
      --api-key [REDACTED]   API key for authentication
      --api-url string   API base URL to target a specific environment (env: AGENT_WALLET_API_URL)
      --timeout float    HTTP timeout in seconds (default 30)
  -v, --verbose          Enable debug logging

Use "caw payment [command] --help" for more information about a command.
