Manage on-chain transactions for a wallet.

Subcommands let you transfer tokens, submit contract calls, sign messages,
estimate fees, and manage in-flight transactions via cancel (drop) or
replace-by-fee (speedup). All mutating operations are evaluated against
active policies before submission.

Usage:
  caw tx [command]

Available Commands:
  call                  Submit an EVM or Solana contract call with policy enforcement
  drop                  Cancel or RBF-drop a pending or broadcasting transaction
  estimate-call-fee     Estimate contract call fee without submitting; recommended before large calls
  estimate-transfer-fee Estimate transfer fee without submitting or running policy checks
  get                   Get details of a single transaction record
  list                  List transaction records, filterable by status, token, chain, or address
  sign-message          Sign a message (EIP-712, etc.)
  speedup               Speed up a broadcasting transaction with higher fees (RBF)
  transfer              Transfer tokens with policy enforcement

Flags:
  -h, --help   help for tx

Global Flags:
      --api-key [REDACTED]   API key for authentication
      --api-url string   API base URL to target a specific environment (env: AGENT_WALLET_API_URL)
      --timeout float    HTTP timeout in seconds (default 30)
  -v, --verbose          Enable debug logging

Use "caw tx [command] --help" for more information about a command.
