Manage Micropayment Protocol (MPP) payment sessions. Subcommands let
you list active sessions, close individual or all sessions, and withdraw
deposited funds after a channel is closed on-chain.

Usage:
  caw payment session [command]

Available Commands:
  close       Close an active MPP session
  close-all   Close all active MPP sessions
  list        List active MPP sessions
  withdraw    Withdraw funds after on-chain close grace period

Flags:
  -h, --help   help for session

Global Flags:
      --api-key [REDACTED]   API key for authentication
      --api-url string   API base URL to target a specific environment (env: AGENT_WALLET_API_URL)
      --timeout float    HTTP timeout in seconds (default 30)
  -v, --verbose          Enable debug logging

Use "caw payment session [command] --help" for more information about a command.
